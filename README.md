# Quiz Multiplayer em Tempo Real — Estilo Kahoot

**Disciplina:** Programação para Dispositivos Móveis  
**Projeto Inicial**

## Objetivo do Projeto

Desenvolver uma aplicação mobile/web, semelhante ao Kahoot, onde vários usuários podem participar de um jogo de perguntas e respostas em tempo real.

Neste projeto, um usuário cria uma sala, cadastra as perguntas e respostas, define o tempo de cada pergunta e convida outros jogadores. Durante o jogo, quem responder corretamente e mais rápido ganha mais pontos. Ao final da partida, é exibido o scoreboard com a pontuação de todos os jogadores.

O objetivo acadêmico é aplicar os conceitos da disciplina de Programação para Dispositivos Móveis, como desenvolvimento de interfaces mobile, consumo de APIs, comunicação em tempo real e integração entre frontend mobile e backend.

## Tecnologias Previstas

- **Frontend:** Expo + React Native
- **Backend:** Java Spring
- **Banco de Dados:** PostgreSQL
